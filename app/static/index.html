    NAME

    thesis-rag — chat with the 19 papers behind a skripsi

    DESCRIPTION

    Each message is matched against 647 passages from the papers using keyword search and meaning-based search together. Follow-ups like “what about the second one?” are first rewritten into a full question so the search knows what “it” means; “say that more simply” reuses the passages already found. The best passages, their neighbouring text and any tables they refer to go to Claude (Haiku 4.5) with the recent conversation. Anything it says about a paper must come from those passages and be cited; it may add plainly-labelled general background to explain.

    EVALUATION

    On a 66-question test set, the passage containing the answer reaches the model for 92% of questions, and 70% when questions are reworded in everyday language.

    NOTES

    The conversation is kept in this browser tab only and is gone when you close it.
